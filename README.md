# taprss

Tap structured JSON rss payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/taprss/

## Install / run

```bash
git clone https://github.com/theworker02/taprss.git
cd taprss
node src/cli.js
node --test
```
